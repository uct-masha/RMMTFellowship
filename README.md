# RMMTFellowship
The Regional Malaria Modelling Translational (RMMT) Fellowship is a six-month executive programme designed to strengthen the use of modelling in malaria decision-making.

This repository contains the curriculum, training materials and supplementary tools required to deliver the RMMT fellowship.
